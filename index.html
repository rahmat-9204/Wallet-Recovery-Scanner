هشدار امنیتی: عبارت بازیابی را در GitHub Pages عمومی وارد نکن. این برنامه از کتابخانه‌های خارجی و APIهای عمومی استفاده می‌کند. قبل از استفاده واقعی، با عبارت آزمایشی آن را بررسی کن.
